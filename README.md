# FhooKkkDiya

A dark, local-first React Native + Expo daily expense tracker with a sarcastic Hinglish personality.

## What changed in the redesign

- Rebranded the app and storage namespace from Spendly to FhooKkkDiya.
- Added the supplied Gutz Bhoiii avatar to the welcome screen and app header.
- Added a new first-launch welcome experience with the requested punchline.
- Added dark minimal visual system, animated screen transitions, avatar press animation, ambient orb motion, and tactile button feedback.
- Added Hinglish/Urdu-flavoured sarcastic copy throughout the expense workflow.
- Added long-press delete for expense rows.
- Kept all expense and preference data on-device with AsyncStorage.
- Closing and reopening the app does not reset stored expenses or preferences.

## Run

```bash
npm install
npm start
```

This branch is the redesign working branch.
